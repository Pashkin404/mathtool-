Описание: Вывод справки по конкретной команде solve. Показывает все доступные флаги и параметры для решения уравнений.


КОМАНДА 1: solve (Решение квадратных и линейных уравнений)
----------------------------------------------------------------------
Команда: python mathtest.py solve -a 1 -b -3 -c 2
stdin: <пусто>
stdout:
Уравнение квадратное
Дискриминант: 1
x1 = 2.000
x2 = 1.000
Код возврата: 0
Описание: Успешное решение квадратного уравнения с двумя действительными корнями.

Команда: python mathtest.py solve -a 0 -b 2 -c -5
stdin: <пусто>
stdout:
Уравнение линейное
x = 2.500
Код возврата: 0
Описание: Решение линейного уравнения (коэффициент A равен 0).

Команда: python mathtest.py solve -a 1 -b 0 -c 5
stdin: <пусто>
stdout:
Уравнение квадратное
Дискриминант: -20
Действительных корней нет
Код возврата: 0
Описание: Квадратное уравнение, не имеющее корней в действительных числах (дискриминант меньше 0).
